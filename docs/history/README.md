# History

These documents describe the full Observatory app up to build 44 (October 2026): its native Mac and Windows apps, pairing, sharing, packaging and release checks. That app was replaced by the lean hub rebuild described in [the design notes](../HUB-PLAN.md). The documents are kept unchanged, with their original dates and limitations, as the record of that work. They do not describe the current code. The full source of that version is on the `archive/full-app` tag.
